# Hotel Reservation API Testing (Postman)

This project contains API tests for the Restful Booker API using Postman.

## Folder Structure
- `collections/`: Postman collection file
- `environments/`: Environment variable files
- `README.md`: Project documentation

## How to Run
1. Import `hotel-reservation.postman_collection.json` into Postman
2. Select the proper environment
3. Run the collection with Runners
